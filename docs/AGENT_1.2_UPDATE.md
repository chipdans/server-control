# Обновление агента до 1.2.0

Этот выпуск добавляет реальные показатели CPU, памяти, диска, сети и
температуры на вкладку **Главная** клиента 0.3.0. Он совместим с уже созданным
Cloudflare Worker: развёртывание Worker и изменение его секретов не нужны.

## Что изменится

- агент отправляет компактный снимок ресурсов раз в heartbeat;
- при недоступном Control Hub очередь строк консоли ограничена 2 000
  событиями или 2 МиБ, вместо неограниченного роста памяти;
- RCON собирает многочастный ответ команды целиком;
- диагностические команды теперь сравниваются с allow-list **целиком**, а не
  по началу строки. Это не влияет на `uptime`, `free -h`, `df -h` и `lsblk`.

Старое поле `allow_shell_prefixes` продолжает читаться для совместимости, но
каждая его строка теперь тоже является точной командой. Для новой конфигурации
используйте `allow_shell_commands` из `agent/config.example.json`.

## Проверка после установки

1. В статусе systemd агент должен быть `active (running)`.
2. В его журнале должна появиться строка `Server Control agent 1.2.0 started.`
3. В Windows-клиенте 0.3.0 откройте **Главная**. Через несколько секунд должны
   появиться CPU, память, диск и скорость сети. Температура может быть
   недоступна на оборудовании без доступного системного датчика — это нормально.

Не меняйте значения `hub_url`, ключ агента или пароль RCON ради этого
обновления. Они остаются в существующей закрытой конфигурации на сервере.
