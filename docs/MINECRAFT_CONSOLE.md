# Живая консоль Minecraft

Версия клиента 0.2.0 делает вкладку **Minecraft** отдельной живой консолью:

- новые строки `latest.log` появляются примерно раз в секунду, независимо от
  Linux-консоли;
- отправленная команда сразу показывается локально как `▶ /команда`;
- агент забирает очередь раз в секунду и передаёт команду в локальный RCON;
- результат RCON появляется в общей консоли с меткой `[RCON]`;
- `Tab` предлагает команды, игроков, селекторы (`@a`, `@p` и другие) и
  распространённые аргументы; `↑`/`↓` выбирают подсказку или прежнюю команду.

Слэш в начале можно вводить как в игре (`/gamemode creative`), но для RCON он
автоматически убирается. Команды с модами дополняются именами, которые сервер
возвращает через `help`; стандартные команды Minecraft доступны сразу.

## Что означает индикатор запуска

Forge и модпаки не публикуют единый честный процент загрузки. Поэтому индикатор
двигается только по реально найденным строкам `latest.log`:

| Этап в приложении | Примеры строк, по которым он определяется |
| --- | --- |
| Запускаю Java и Forge | `ModLauncher`, `FMLLoader`, `Loading Minecraft` |
| Сканирую моды | `Found mod file`, `ModDiscoverer` |
| Инициализирую моды | `Constructing Mods`, `Common Setup`, `ModLoading` |
| Регистрирую содержимое | `GameData`, `Registries`, `Registering` |
| Загружаю мир | `Preparing level`, `Loading level` |
| Подготавливаю спавн | `Preparing spawn area: N%`, `Preparing start region: N%` |
| Запускаю службы Minecraft | `Starting RCON`, `Starting Minecraft server` |
| Сервер готов | `Done (...s)! For help, type "help"` или успешный RCON `list` |

`WARN` от mixin, проверки версий Forge и сообщения отдельных модов часто не
являются ошибками — они остаются видны в консоли, но не сбрасывают прогресс.
Индикатор показывает **Ошибка запуска** только при серьёзных маркерах, например
`FATAL`, `Crash Report`, `Exception in server tick loop` или `Failed to start`.

## Ограничение RCON

Стандартный RCON умеет запускать команды и возвращать их вывод, но не имеет
протокола настоящих Brigadier-подсказок, которые игровой клиент получает от
сервера при нажатии Tab. Текущая реализация закрывает наиболее частые случаи
без установки модов. Для полного автодополнения всех аргументов из модов нужен
маленький серверный Forge-мод, который отдаёт Brigadier suggestions только
локальному агенту; он не требует открыть новый порт в интернет.
