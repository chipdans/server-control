# Краткие правила безопасности

1. Не давайте обычным игрокам право `server_command`: оно предназначено только
   для владельца или полностью доверенных администраторов.
2. Оставляйте RCON доступным только по локальной сети сервера; не пробрасывайте
   его через роутер.
3. Выдавайте пользователям минимальные права. Для игрока обычно достаточно
   `minecraft_view` и `minecraft_command`.
4. При потере ноутбука или подозрении на утечку отключите соответствующего
   пользователя в разделе **Пользователи** и смените его пароль.
5. При утечке OAuth-токена Яндекса перевыпустите его и сразу замените секрет
   `YANDEX_OAUTH_TOKEN` в Cloudflare.
6. Включите двухфакторную аутентификацию для аккаунтов Cloudflare, GitHub и
   Яндекса владельца.
