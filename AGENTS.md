# Работа над Server Control

- Общайтесь с пользователем по-русски, кратко: результат, проверка, существенные ограничения.
- Сначала сверяйте актуальную ветку. Не включайте чужие незавершённые изменения в релиз.
- Ищите только нужные файлы через rg; не перечитывайте весь проект и инструкции без причины.
- Выполняйте целевые проверки изменённого поведения. Полную сборку запускайте один раз перед выпуском; повторяйте только после ошибки или существенной правки.
- Для файловых операций проверяйте границы каталогов, отмену передачи, конфликты записи и сохранность исходных данных. Это обязательные проверки по риску потери данных.
- Сохраняйте действующие ограничения доступа и ранее выданные разрешения пользователя. Не запрашивайте повторное разрешение на уже разрешённую публикацию.
- Не возвращайте удалённый экспорт непереведённых строк.
